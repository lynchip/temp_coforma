Welcome

This site is used for testing and previewing the CoForma project. It is served directly from GitHub Pages so no custom domain or build step is required.

About This Page

Edit index.html and style.css in VS Code, push to GitHub, and GitHub Pages will automatically update this site.

Getting Started

  • Make your changes in VS Code.
  • Commit and push to the main branch.
  • Go to Settings → Pages in the GitHub repository and set the source to the main branch, root folder.
  • Your site will be live at https://<username>.github.io/temp_coforma/.
