# temp_coforma

Temporary repo for CoForma – a static website served via **GitHub Pages**.

## Live Site

Once GitHub Pages is enabled, the site will be available at:

```
https://<your-github-username>.github.io/temp_coforma/
```

## Enabling GitHub Pages

1. Go to the repository on GitHub.
2. Click **Settings → Pages**.
3. Under *Build and deployment → Source*, select **Deploy from a branch**.
4. Choose the **main** branch and the **/ (root)** folder.
5. Click **Save**. GitHub will build and publish the site within a minute.

## Local Preview

Open `index.html` directly in a browser, or use the VS Code
[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
extension for hot-reload previewing.
